# Model avatar (opsional)

Letakkan model avatar mahasiswa di sini dengan nama **`telkom-student.glb`**.
Jika file ada, game otomatis memakainya; jika tidak ada (atau gagal dimuat), avatar prosedural berjaket almamater merah dipakai.

Ketentuan model:
- Menghadap sumbu **+Z**, kaki berada di y = 0 (diskalakan otomatis ke tinggi 1.72 m).
- Klip animasi dikenali dari nama: mengandung `idle`, `walk`/`jalan`, `run`/`lari`.
- Jaket almamater merah Telkom University, celana hitam, sepatu.
- Logo resmi Telkom University harus berasal dari aset resmi; repo ini sengaja tidak membuat logo sendiri.
